## 🚚 Projeto em destaque — MOVAIQ

O **MOVAIQ** é uma plataforma SaaS para gestão de transportes e fretes, desenvolvida com backend e frontend separados.

### Backend
**Node.js • NestJS • TypeScript • PostgreSQL • Prisma • JWT • Passport • Jest • Swagger**

Principais recursos:
- Autenticação com JWT
- Controle de acesso por perfil (RBAC)
- Arquitetura multiempresa
- Gestão de usuários, clientes, motoristas, veículos e cargas
- Gestão de fretes e histórico de status
- Rastreamento
- Upload e gerenciamento de documentos
- Despesas e indicadores financeiros
- Dashboard
- Logs de auditoria
- Testes automatizados
- GitHub Actions

➡️ **Backend:** https://github.com/eckstein75/movaiq

### Frontend
**React • TypeScript • Vite • Axios • React Router • CSS responsivo**

Principais recursos:
- Login e sessão com JWT
- Navegação conforme perfil do usuário
- Dashboard operacional e financeiro
- Gestão de fretes
- Clientes, motoristas, veículos e cargas
- Rastreamento
- Documentos e despesas
- Auditoria
- Layout responsivo

➡️ **Frontend:** https://github.com/eckstein75/movaiq-frontend
